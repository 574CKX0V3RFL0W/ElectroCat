I received a package with AO3400A SOT23 MOS-FETs. I would like to put together a sticker with the basic info about this part so that I can put it on the ziplock bag. It will be printed with the "cat thermal printer" (sw interface available at https://print.natey.me/ ) with native horizontal resolution of  384 px, which is always to be precisely kept. 
Also, while doing this the first time, I would like to automatize this as much as possible for the following electronic parts purchases, by making a sort of autofill registration form (preferably in a form of a web interface, such as the one for the cat printer), that would also connect to a spreadsheet (Excel-viewable) that would be backed up locally (every time new part is registered) on my computer's drive and catalogize all the parts that I buy from now on. The basic info should include Part name, part type, and the most important parameters, in this case: general type description (N-channel, enhancement type, trench MOSFET, extremely low RDS(ON)); V(ds), I(ds), V(g max.), V(g min.), etc., package (SOT23 in this case), and a sketch of the pinout. Th printed sticker should be at most 384 × 384 px, in png format readable with the printer SW. There would be two input methods. First (full auto) - a browser plugin that could be activated on any web page by right click on the part listing name or into the URL line, selecting "Add to my parts list". Second - manual entry of the part name, by selecting "Add entry". Everything else would auto-fill (and ask for clarifications if in doubt). Then whenever I go to my web interface, I would see all the entries with the parts I already have in the system, the last one added at the top, with fully editable attributes, checkboxes in the leftmost column, and a "print sticker" button in the navbar menu. (Possibility to check several entries and print all at once.)
